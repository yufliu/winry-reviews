# winry-reviews

Public feed of 5-star Airbnb reviews for Winry Stays' Tallahassee listings,
rendered on [winrystays.com](https://winrystays.com). Updated every two weeks by
an automated job. All reviews, including lower ratings, are on
[the Airbnb host profile](https://www.airbnb.com/users/show/1470250776314966495).

Feed: `https://yufliu.github.io/winry-reviews/reviews.json`
